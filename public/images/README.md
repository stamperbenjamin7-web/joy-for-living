# Real photos

Drop your real photos here with these exact filenames and the site will use them
automatically (it falls back to stock photos if a file is missing):

- `hero.jpg` — homepage background (your Palm Beach kiosk / aerial shot)
- `activities/umbrella.jpg` — used on the Beach Chair & Umbrella Delivery section
- `activities/dolphin.jpg`, `activities/sunshine.jpg`, `activities/sail-away.jpg`,
  `activities/locura.jpg`, `activities/jolly-pirates.jpg` — one photo per boat
- `activities/tube.jpg`, `activities/parasailing.jpg`, `activities/jetski.jpg`,
  `activities/kayak.jpg`, `activities/paddleboard.jpg` — watersports
- `activities/bottom-fishing.jpg`, `activities/deep-sea-fishing.jpg` — fishing
- `activities/jeep-tours.jpg`, `activities/utv-tours.jpg` — land tours
- `logo.png` — transparent logo (used in the navbar/footer if you wire it in)

No image editing needed — just match the filename and re-deploy.
